ELECTRONICS TOOLBOX V3
=======================

Run:
1. Extract the ZIP.
2. Double-click run.bat.
3. Use the sidebar to switch between Resistors and Capacitors.

RESISTORS
- 4-band, 5-band and 6-band modes
- Colour -> resistance
- Resistance -> colour
- Tolerance and resistance range
- 6-band TCR display
- Live resistor graphic
- Colour reference table

CAPACITORS
- 3-digit code -> capacitance
- Capacitance -> 3-digit code
- Common code examples
- Explanation of AB x 10^C pF notation
